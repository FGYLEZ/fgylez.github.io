网站历史

Site History

  1. 2024.02

    第一个个人主页上线 纯静态 HTML，用免费空间托管，不仅访问慢，域名还比我命长。

  2. 2025.06

    迁移到自建服务器 荒废了将近一年半重新搞，拿家里的老爷笔记本+IPV6映射搭了个网盘，天天掉线，IPV6 地址还™老变，过段时间就得改 DNS 配置。

  3. 2026.01

    全站界面升级 将 Cloudreve 版本升级到 V4 ，界面焕新，然而域名马上就到期了，而且依旧是多动症 IPV6。

  4. 2026.06

    抛弃网盘，开始写真正的主页 起初想从0搓一个，后来发现凭自己的那点高级技术实在写不出精美的页面，于是动用 AI 大法。搓完之后就吃灰了，因为实在找不到好的托管服务器

  5. 2026.11.14

    正式上线页面 终于发现 Github 托管网站的方法了，火速迁移，并重写界面 UI，巨硬的 Fluent UI。

  6. 2026.11.28

    只是1次优化 将网页卡片布局横向排布，优化空间。并添加了背景图、彩蛋、关于页开你盒卡片等。
